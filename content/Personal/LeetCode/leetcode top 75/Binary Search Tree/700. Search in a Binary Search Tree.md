## Description

<p>You are given the <code>root</code> of a binary search tree (BST) and an integer <code>val</code>.</p>
<p>Find the node in the BST that the node&#39;s value equals <code>val</code> and return the subtree rooted with that node. If such a node does not exist, return <code>null</code>.</p>
<p><strong class="example">Example 1:</strong></p>
![[Personal/LeetCode/Assets/LetCode Assets/search-in-a-binary-search-tree_0.jpg]]
<pre>
<strong>Input:</strong> root = [4,2,7,1,3], val = 2
<strong>Output:</strong> [2,1,3]
</pre>
<p><strong class="example">Example 2:</strong></p>
![[Personal/LeetCode/Assets/LetCode Assets/search-in-a-binary-search-tree_1.jpg]]
<pre>
<strong>Input:</strong> root = [4,2,7,1,3], val = 5
<strong>Output:</strong> []
</pre>
<p><strong>Constraints:</strong></p>
<ul>
	<li>The number of nodes in the tree is in the range <code>[1, 5000]</code>.</li>
	<li><code>1 &lt;= Node.val &lt;= 10<sup>7</sup></code></li>
	<li><code>root</code> is a binary search tree.</li>
	<li><code>1 &lt;= val &lt;= 10<sup>7</sup></code></li>
</ul>

## Solution

```python
from algos.binarysearchtree import Node


def search_in_binary_search_tree(root: Node, key: int):
	if not root:
		return None
	
	if root.val > key:
		return search_in_binary_search_tree(root.left, key)
	elif root.val < key:
		return search_in_binary_search_tree(root.right, key)
	else:
		return root
	

root = Node.create_bst([4,2,7,1,3])
val = 2
root = search_in_binary_search_tree(root, val)
root.inorder_print()

root = Node.create_bst([4,2,7,1,3])
val = 5
root = search_in_binary_search_tree(root, val)
print(root)
```
