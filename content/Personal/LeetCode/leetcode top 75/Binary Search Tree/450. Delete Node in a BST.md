## Description

<p>Given a root node reference of a BST and a key, delete the node with the given key in the BST. Return <em>the <strong>root node reference</strong> (possibly updated) of the BST</em>.</p>
<p>Basically, the deletion can be divided into two stages:</p>
<ol>
	<li>Search for a node to remove.</li>
	<li>If the node is found, delete the node.</li>
</ol>
<p><strong class="example">Example 1:</strong></p>

![[Personal/LeetCode/Assets/LetCode Assets/delete-node-in-a-bst_0.jpg]]

<pre>
<strong>Input:</strong> root = [5,3,6,2,4,null,7], key = 3
<strong>Output:</strong> [5,4,6,2,null,null,7]
<strong>Explanation:</strong> Given key to delete is 3. So we find the node with value 3 and delete it.
One valid answer is [5,4,6,2,null,null,7], shown in the above BST.
Please notice that another valid answer is [5,2,6,null,4,null,7] and it&#39;s also accepted.
</pre>

![[Personal/LeetCode/Assets/LetCode Assets/delete-node-in-a-bst_1.jpg]]
<p><strong class="example">Example 2:</strong></p>
<pre>
<strong>Input:</strong> root = [5,3,6,2,4,null,7], key = 0
<strong>Output:</strong> [5,3,6,2,4,null,7]
<strong>Explanation:</strong> The tree does not contain a node with value = 0.
</pre>
<p><strong class="example">Example 3:</strong></p>
<pre>
<strong>Input:</strong> root = [], key = 0
<strong>Output:</strong> []
</pre>
<p><strong>Constraints:</strong></p>
<ul>
	<li>The number of nodes in the tree is in the range <code>[0, 10<sup>4</sup>]</code>.</li>
	<li><code>-10<sup>5</sup> &lt;= Node.val &lt;= 10<sup>5</sup></code></li>
	<li>Each node has a <strong>unique</strong> value.</li>
	<li><code>root</code> is a valid binary search tree.</li>
	<li><code>-10<sup>5</sup> &lt;= key &lt;= 10<sup>5</sup></code></li>
</ul>
<p><strong>Follow up:</strong> Could you solve it with time complexity <code>O(height of tree)</code>?</p>

## Solution

Find the node and replace it with another node if possible. Finding node is easy, just choosing either to go left or right. Once node is found we need to delete it and,
if only one child exists move that up. No child we do not need to move anything up. But if it has two children we have two options, keep the node and follow the left node's
right most node, we know by fact that that node will be smaller than the right node of the deleted node. So we can just swap the values and remove that node from the bottom.
Same can be done for the right node too, left most of the right node is valid for swapping. Just matter of taste.

Let's implement the algo

```python
from algos.binarysearchtree import Node


def delete_node_in_bst(root: Node, key):
	if not root:
		return root

	if root.val > key:
		root.left = delete_node_in_bst(root.left, key)
	elif root.val < key:
		root.right = delete_node_in_bst(root.right, key)
	else:
		if not root.left and not root.right:
			return None

		if not root.left:
			return root.right

		if not root.right:
			return root.left

		successor = root.right

		while successor.left:
			successor = successor.left

		root.val = successor.val
		root.right = delete_node_in_bst(root.right, successor.val)

	return root

root = Node.create_bst([5,3,6,2,4,7])
key = 3

result = delete_node_in_bst(root, key)
result.inorder_print()

root = Node.create_bst([5,3,6,2,4,7])
key = 0

result = delete_node_in_bst(root, key)
result.inorder_print()
```
