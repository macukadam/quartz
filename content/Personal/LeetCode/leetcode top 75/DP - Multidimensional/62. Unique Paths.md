## Description

<p>There is a robot on an <code>m x n</code> grid. The robot is initially located at the <strong>top-left corner</strong> (i.e., <code>grid[0][0]</code>). The robot tries to move to the <strong>bottom-right corner</strong> (i.e., <code>grid[m - 1][n - 1]</code>). The robot can only move either down or right at any point in time.</p>
<p>Given the two integers <code>m</code> and <code>n</code>, return <em>the number of possible unique paths that the robot can take to reach the bottom-right corner</em>.</p>
<p>The test cases are generated so that the answer will be less than or equal to <code>2 * 10<sup>9</sup></code>.</p>
<p><strong class="example">Example 1:</strong></p>

![[Personal/LeetCode/Assets/LetCode Assets/unique-paths_0.png]]
<pre>
<strong>Input:</strong> m = 3, n = 7
<strong>Output:</strong> 28
</pre>
<p><strong class="example">Example 2:</strong></p>
<pre>
<strong>Input:</strong> m = 3, n = 2
<strong>Output:</strong> 3
<strong>Explanation:</strong> From the top-left corner, there are a total of 3 ways to reach the bottom-right corner:
1. Right -&gt; Down -&gt; Down
2. Down -&gt; Down -&gt; Right
3. Down -&gt; Right -&gt; Down
</pre>
<p><strong>Constraints:</strong></p>
<ul>
	<li><code>1 &lt;= m, n &lt;= 100</code></li>
</ul>

## Solution

This is a dp problem because the main problem consist same sub problems. So first we can try brute force our way to a solution with recursion. Very bad time complexity 0($2^N$)

```python
def unique_paths(m: int, n: int, i: int = 0, j: int = 0) -> int:
	if i == m - 1 and j == n - 1:
	    return 1
	if i >= m or j >= n:
		return 0
		
	return unique_paths(m, n, i + 1, j) + unique_paths(m, n, i, j + 1)


print(unique_paths(m = 3, n = 7))
print(unique_paths(m = 3, n = 2))
```

We can add memoization to this, which will make the algorithm one pass thus O($N$)

```python
def unique_paths(m: int, n: int) -> int:
    memo = [[0] * n for _ in range(m)]

    def dp(i, j):
        if i == m - 1 and j == n - 1:
            return 1

        if i >= m or j >= n:
            return 0

        if memo[i][j] != 0:
            return memo[i][j]

        memo[i][j] = dp(i + 1, j) + dp(i, j + 1)
        return memo[i][j]

    return dp(0, 0)


print(unique_paths(m=3, n=7))
print(unique_paths(m=3, n=2))
```

Tabulation time. Space complexity here is O($N*M$)

But actually by using only one row we can still reach the answer. Thus reducing space complexity to O($N$)

```python
def unique_paths(m: int, n: int) -> int:
    dp = [1] * n

    for i in range(1, m):
        for j in range(1, n):
            dp[j] = dp[j] + dp[j - 1]
	
    return dp[n - 1]


print(unique_paths(m=3, n=7))
print(unique_paths(m=3, n=2))
```
