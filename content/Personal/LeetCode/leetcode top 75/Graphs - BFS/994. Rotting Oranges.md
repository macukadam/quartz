## Description

<p>You are given an <code>m x n</code> <code>grid</code> where each cell can have one of three values:</p>
<ul>
	<li><code>0</code> representing an empty cell,</li>
	<li><code>1</code> representing a fresh orange, or</li>
	<li><code>2</code> representing a rotten orange.</li>
</ul>
<p>Every minute, any fresh orange that is <strong>4-directionally adjacent</strong> to a rotten orange becomes rotten.</p>
<p>Return <em>the minimum number of minutes that must elapse until no cell has a fresh orange</em>. If <em>this is impossible, return</em> <code>-1</code>.</p>
<p><strong class="example">Example 1:</strong></p>

![[Personal/LeetCode/Assets/LetCode Assets/rotting-oranges_0.png]]
<pre>
<strong>Input:</strong> grid = [[2,1,1],[1,1,0],[0,1,1]]
<strong>Output:</strong> 4
</pre>
<p><strong class="example">Example 2:</strong></p>
<pre>
<strong>Input:</strong> grid = [[2,1,1],[0,1,1],[1,0,1]]
<strong>Output:</strong> -1
<strong>Explanation:</strong> The orange in the bottom left corner (row 2, column 0) is never rotten, because rotting only happens 4-directionally.
</pre>
<p><strong class="example">Example 3:</strong></p>
<pre>
<strong>Input:</strong> grid = [[0,2]]
<strong>Output:</strong> 0
<strong>Explanation:</strong> Since there are already no fresh oranges at minute 0, the answer is just 0.
</pre>
<p><strong>Constraints:</strong></p>
<ul>
	<li><code>m == grid.length</code></li>
	<li><code>n == grid[i].length</code></li>
	<li><code>1 &lt;= m, n &lt;= 10</code></li>
	<li><code>grid[i][j]</code> is <code>0</code>, <code>1</code>, or <code>2</code>.</li>
</ul>

## Solution

We need to find the minimum number of minutes. To do that, we first need to find all the rotten oranges. From every rotten orange, the rot can start spreading to adjacent fresh oranges.

A brute-force approach would be to iterate over the grid minute by minute. In each iteration, we could scan the whole grid and find fresh oranges that are adjacent to a rotten one, mark them as rotten, and increase the minute counter. If at the end there are still fresh oranges left that were never reached, we can return `-1`.

The problem with this approach is that it does a lot of repeated work. The same rotten oranges are checked over and over again in every iteration, which makes it inefficient. We could try to keep track of already processed rotten oranges to avoid rechecking their neighbors, but that starts to get messy and still isn't very clean.

Instead, we can model this problem as a **BFS**. All initially rotten oranges are the starting points, and each BFS level represents one minute. As we expand the BFS, the rot spreads to adjacent fresh oranges, and we never revisit the same cell again.

This way, we avoid redundant work and get the minimum number of minutes naturally.

```python
from typing import List
from collections import deque


def rotting_oranges(grid: List[List[int]]) -> int:
    rotting_oranges = deque()
    fresh_oranges = set()

    dirs = [(1, 0), (0, 1), (-1, 0), (0, -1)]

    n = len(grid)
    m = len(grid[0])

    for i in range(n):
        for j in range(m):
            if grid[i][j] == 2:
                rotting_oranges.append((i, j))
            elif grid[i][j] == 1:
                fresh_oranges.add((i, j))

    minutes = 0
    while rotting_oranges and fresh_oranges:
        minutes += 1
        for _ in range(len(rotting_oranges)):
            x, y = rotting_oranges.popleft()

            for dx, dy in dirs:
                nx, ny = x + dx, y + dy
                if 0 <= nx < n and 0 <= ny < m and (nx, ny) in fresh_oranges:
                    rotting_oranges.append((nx, ny))
                    fresh_oranges.remove((nx, ny))

    return minutes if not fresh_oranges else -1



grid = [[2,1,1],[1,1,0],[0,1,1]]
print(rotting_oranges(grid))

grid = [[2,1,1],[0,1,1],[1,0,1]]
print(rotting_oranges(grid))

grid = [[0,2]]
print(rotting_oranges(grid))
```
