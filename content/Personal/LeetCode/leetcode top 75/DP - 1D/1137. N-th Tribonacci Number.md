## Description

<p>The Tribonacci sequence T<sub>n</sub> is defined as follows:&nbsp;</p>
<p>T<sub>0</sub> = 0, T<sub>1</sub> = 1, T<sub>2</sub> = 1, and T<sub>n+3</sub> = T<sub>n</sub> + T<sub>n+1</sub> + T<sub>n+2</sub> for n &gt;= 0.</p>
<p>Given <code>n</code>, return the value of T<sub>n</sub>.</p>
<p><strong class="example">Example 1:</strong></p>
<pre>
<strong>Input:</strong> n = 4
<strong>Output:</strong> 4
<strong>Explanation:</strong>
T_3 = 0 + 1 + 1 = 2
T_4 = 1 + 1 + 2 = 4
</pre>
<p><strong class="example">Example 2:</strong></p>
<pre>
<strong>Input:</strong> n = 25
<strong>Output:</strong> 1389537
</pre>
<p><strong>Constraints:</strong></p>
<ul>
	<li><code>0 &lt;= n &lt;= 37</code></li>
	<li>The answer is guaranteed to fit within a 32-bit integer, ie. <code>answer &lt;= 2^31 - 1</code>.</li>
</ul>

## Solution

Let's start with brute force recursive algorithm.

```python
def nth_tribonacci_number(n: int) -> int:
	if n == 0:
		return n
	elif n == 1 or n == 2:
		return 1
		
	return nth_tribonacci_number(n-3) + nth_tribonacci_number(n -2) + nth_tribonacci_number(n -1)
	
print(nth_tribonacci_number(4))
print(nth_tribonacci_number(25))
```

Of course this approach is extremely slow. Because calls the same functions over and over again. O($3^n$). This is terrible for our poor machine. I don't even know if we can run 25 in web interface version. So let's add memoization.

```python
from collections import defaultdict
from typing import List


def nth_tribonacci_number(n: int, dp: List[int]) -> int:
	dp = [0, 1, 1] + [0] * (n - 1)
	if n < 3: return dp[n]
	
	for i in range(3, n + 1):
		dp[i] = dp[i - 1] + dp[i - 2] + dp[i - 3]
	
	return dp[n]
	
print(nth_tribonacci_number(4, []))
print(nth_tribonacci_number(25, []))
```

Now let's the time complexity much sane O($N$). Very cool indeed. But space complexity is still O($N$). While we only use three elements from dp array, we are wasting some space. We can instead just hold the last 3 tribonacci numbers. That way we would achieve O($1$). 

```python
from collections import defaultdict
from typing import List


def nth_tribonacci_number(n: int) -> int:
	fib1, fib2, fib3 = 0, 1, 1
	if n <= 1: return 0
	if n < 3: return 1
	
	for val in range(3, n + 1):
		fib1, fib2, fib3 = fib2, fib3, fib1 + fib2 + fib3
		
	return fib3
	
print(nth_tribonacci_number(4))
print(nth_tribonacci_number(25))
```
