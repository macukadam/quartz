## Description

<p>You are given an integer array <code>cost</code> where <code>cost[i]</code> is the cost of <code>i<sup>th</sup></code> step on a staircase. Once you pay the cost, you can either climb one or two steps.</p>
<p>You can either start from the step with index <code>0</code>, or the step with index <code>1</code>.</p>
<p>Return <em>the minimum cost to reach the top of the floor</em>.</p>
<p><strong class="example">Example 1:</strong></p>
<pre>
<strong>Input:</strong> cost = [10,<u>15</u>,20]
<strong>Output:</strong> 15
<strong>Explanation:</strong> You will start at index 1.
- Pay 15 and climb two steps to reach the top.
The total cost is 15.
</pre>
<p><strong class="example">Example 2:</strong></p>
<pre>
<strong>Input:</strong> cost = [<u>1</u>,100,<u>1</u>,1,<u>1</u>,100,<u>1</u>,<u>1</u>,100,<u>1</u>]
<strong>Output:</strong> 6
<strong>Explanation:</strong> You will start at index 0.
- Pay 1 and climb two steps to reach index 2.
- Pay 1 and climb two steps to reach index 4.
- Pay 1 and climb two steps to reach index 6.
- Pay 1 and climb one step to reach index 7.
- Pay 1 and climb two steps to reach index 9.
- Pay 1 and climb one step to reach the top.
The total cost is 6.
</pre>
<p><strong>Constraints:</strong></p>
<ul>
	<li><code>2 &lt;= cost.length &lt;= 1000</code></li>
	<li><code>0 &lt;= cost[i] &lt;= 999</code></li>
</ul>

## Solution

The first thing we can do is brute forcing every possibility with recursion. And select min from all the potential step candidates jumping either one or two steps. This solution is has quite bad time complexity: O($2^n$). 

```python
def min_cost_climbing_stairs(cost):
    def dp(n):
        if n >= len(cost):
            return 0
        return cost[n] + min(dp(n + 1), dp(n + 2))

    return min(dp(0), dp(1))

cost = [1,100,1,1,1,100,1,1,100,1]
print(min_cost_climbing_stairs(cost))

cost = [10,15,20]
print(min_cost_climbing_stairs(cost))
```

We can improve this by memoization.

```python
from collections import defaultdict


def min_cost_climbing_stairs(cost):
	memo = defaultdict(int)
	
	def dp(n):
		if n in memo: return memo[n]
		
		if n > len(cost) - 3:
			memo[n] = cost[n]
			return memo[n]
		
		memo[n] = cost[n] + min(dp(n + 1), dp(n + 2))
		return memo[n]
		
	return min(dp(0), dp(1))

cost = [1,100,1,1,1,100,1,1,100,1]
print(min_cost_climbing_stairs(cost))

cost = [10,15,20]
print(min_cost_climbing_stairs(cost))
```

This solution reduces the time complexity to O($N$). And space complexity is O($N$) too. We just have a memo array length of N. Like in the [[Personal/LeetCode/leetcode top 75/DP - 1D/198. House Robber\|House Robber]] question we can use iterative and get rid of recursion overhead.  

```python
from collections import defaultdict


def min_cost_climbing_stairs(cost):
	dp = cost[:2] + [0] * (len(cost) - 2)
	dp[0] = cost[0]
	dp[1] = cost[1]
	
	for i in range(2, len(cost)):
		dp[i] = cost[i] + min(dp[i - 1], dp[i - 2])
		
	return min(dp[-1], dp[-2])

cost = [1,100,1,1,1,100,1,1,100,1]
print(min_cost_climbing_stairs(cost))

cost = [10,15,20]
print(min_cost_climbing_stairs(cost))
```

Now space complexity is still  O($N$). But we are only using 2 elements from whole dp array. We can again reduce space complexity to O($1$). 

```python
def min_cost_climbing_stairs(cost):
    prev1 = prev2 = 0
    for c in cost:
        prev1, prev2 = prev2, c + min(prev1, prev2)
    return min(prev1, prev2)

cost = [1,100,1,1,1,100,1,1,100,1]
print(min_cost_climbing_stairs(cost))

cost = [10,15,20]
print(min_cost_climbing_stairs(cost))
