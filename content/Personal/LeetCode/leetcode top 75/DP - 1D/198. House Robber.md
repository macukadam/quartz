## Description

<p>You are a professional robber planning to rob houses along a street. Each house has a certain amount of money stashed, the only constraint stopping you from robbing each of them is that adjacent houses have security systems connected and <b>it will automatically contact the police if two adjacent houses were broken into on the same night</b>.</p>
<p>Given an integer array <code>nums</code> representing the amount of money of each house, return <em>the maximum amount of money you can rob tonight <b>without alerting the police</b></em>.</p>
<p><strong class="example">Example 1:</strong></p>
<pre>
<strong>Input:</strong> nums = [1,2,3,1]
<strong>Output:</strong> 4
<strong>Explanation:</strong> Rob house 1 (money = 1) and then rob house 3 (money = 3).
Total amount you can rob = 1 + 3 = 4.
</pre>
<p><strong class="example">Example 2:</strong></p>
<pre>
<strong>Input:</strong> nums = [2,7,9,3,1]
<strong>Output:</strong> 12
<strong>Explanation:</strong> Rob house 1 (money = 2), rob house 3 (money = 9) and rob house 5 (money = 1).
Total amount you can rob = 2 + 9 + 1 = 12.
</pre>
<p><strong>Constraints:</strong></p>
<ul>
	<li><code>1 &lt;= nums.length &lt;= 100</code></li>
	<li><code>0 &lt;= nums[i] &lt;= 400</code></li>
</ul>

# Solution

We cannot use a greedy strategy because a local maximum choice can prevent a better global solution. The problem has overlapping subproblems, so we use dynamic programming to decide at each house whether to rob it or skip it based on previous results. Let's first solve it without memoization and with recursion.

```python
from typing import List


def house_robber(nums: List[int], i: int = 0) -> int:
	if i > len(nums) - 1: return 0
	return max(house_robber(nums, i + 1), nums[i] + house_robber(nums, i + 2))
	
nums = [1,2,3,1]
print(house_robber(nums))

nums = [2,7,9,3,1]
print(house_robber(nums))
```

The time complexity of above solution is exponential, O($2^n$). We are calling same function with same variables again and again. To prevent that let's add memoization.

```python
from typing import List
from collections import defaultdict


def house_robber(nums: List[int], i: int, memo) -> int:
	if i > len(nums) - 1: return 0
	if i in memo: return memo[i]
	memo[i] = max(house_robber(nums, i + 1, memo), nums[i] + house_robber(nums, i + 2, memo))
	return memo[i]
	
nums = [1,2,3,1]
print(house_robber(nums, 0, defaultdict(int)))

nums = [2,7,9,3,1]
print(house_robber(nums, 0, defaultdict(int)))
```

Now with this implementation we have optimal time complexity O(N). This is a great solution already. Space complexity is O(N) due to recursion. We still rely on recursion and extra memory, so we can simplify this using a bottom-up approach.

```python
from typing import List


def house_robber(nums: List[int]) -> int:
	if not nums: return 0
	n = len(nums)
	memo = [0] * (n + 1)
	memo[1] = nums[0]
	
	for i in range(1, n):
		memo[i+1] = max(memo[i], memo[i-1] + nums[i])

	return memo[n]
	
nums = [1,2,3,1]
print(house_robber(nums))

nums = [2,7,9,3,1]
print(house_robber(nums))
```

With the solution above we only cared about two values at the whole memo array. So maybe holding it is not ideal. We can reduce space complexity to 0(1) if we only keep two variables as memo[i] and memo[i - 1], as prev1 and prev2

```python
from typing import List


def house_robber(nums: List[int]) -> int:
	prev2 = prev1 = 0
	for n in nums:
		prev2, prev1 = prev1, max(prev1, prev2 + n)
	return prev1

nums = [1,2,3,1]
print(house_robber(nums))

nums = [2,7,9,3,1]
print(house_robber(nums))
```
