# Solution

This problem is a very good demo of BFS. We need the right most node from every level. With BFS we use a queue and pop from left. Which means last item in the queue will be always
rightmost item on the depth.

```python
from algos.binarytree import Node
from collections import deque


def binary_tree_side_view(root: Node):
	queue = deque([root])
	right_most = []
	
	while queue:
		n = len(queue)
		for i in range(len(queue)):
			node = queue.popleft()
			
			if i == n - 1:
				right_most.append(node.val)
				
			if node.left:
				queue.append(node.left)
			if node.right:	
				queue.append(node.right)
				
	return right_most

root = Node.create_binarytree([1,2,3,None,5,None,4])
print(binary_tree_side_view(root))

root = Node.create_binarytree([1,2,3,4,None,None,None,5])
print(binary_tree_side_view(root))

root = Node.create_binarytree([1,None,3])
print(binary_tree_side_view(root))
```
