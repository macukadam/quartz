## Description

<p>For two strings <code>s</code> and <code>t</code>, we say &quot;<code>t</code> divides <code>s</code>&quot; if and only if <code>s = t + t + t + ... + t + t</code> (i.e., <code>t</code> is concatenated with itself one or more times).</p>
<p>Given two strings <code>str1</code> and <code>str2</code>, return <em>the largest string </em><code>x</code><em> such that </em><code>x</code><em> divides both </em><code>str1</code><em> and </em><code>str2</code>.</p>
<p><strong class="example">Example 1:</strong></p>
<div class="example-block">
<p><strong>Input:</strong> <span class="example-io">str1 = &quot;ABCABC&quot;, str2 = &quot;ABC&quot;</span></p>
<p><strong>Output:</strong> <span class="example-io">&quot;ABC&quot;</span></p>
</div>
<p><strong class="example">Example 2:</strong></p>
<div class="example-block">
<p><strong>Input:</strong> <span class="example-io">str1 = &quot;ABABAB&quot;, str2 = &quot;ABAB&quot;</span></p>
<p><strong>Output:</strong> <span class="example-io">&quot;AB&quot;</span></p>
</div>
<p><strong class="example">Example 3:</strong></p>
<div class="example-block">
<p><strong>Input:</strong> <span class="example-io">str1 = &quot;LEET&quot;, str2 = &quot;CODE&quot;</span></p>
<p><strong>Output:</strong> <span class="example-io">&quot;&quot;</span></p>
</div>
<p><strong class="example">Example 4:</strong></p>
<div class="example-block">
<p><strong>Input:</strong> <span class="example-io">str1 = &quot;AAAAAB&quot;, str2 = &quot;AAA&quot;</span></p>
<p><strong>Output:</strong> <span class="example-io">&quot;&quot;</span>​​​​​​​</p>
</div>
<p><strong>Constraints:</strong></p>
<ul>
	<li><code>1 &lt;= str1.length, str2.length &lt;= 1000</code></li>
	<li><code>str1</code> and <code>str2</code> consist of English uppercase letters.</li>
</ul>

## Solution

The key idea here is to see that if a string has a common divisor when we append the two strings to each other we should be able to generate same string.

    str1 = "ABABAB", str2 = "ABAB"
    str1 + str2 = ABABABABAB
    str2 + str1 = ABABABABAB

after understanding this we can say if they are equal we can find the gcd of two strings for sure.

To do that we can get the length of short string and use it to generate a gdc candidate.

```python
def find_gcd_strings(str1, str2):
    if str1 + str2 != str2 + str1:
        return None # lets return None instead if "" for better print

    n1 = len(str1)
    n2 = len(str2)

    for length in range(min(n1, n2), 0, -1):
        sub = str2[:length]
        if str1 == sub * (n1 // length) and n1 % length == 0:
            return sub

    return None # this line will never get reached

str2 = "ABCABC"
str1 = "ABC"
print(find_gcd_strings(str1, str2))

str1 = "LEET"
str2 = "CODE"
print(find_gcd_strings(str1, str2))
```

Or even easier just get the gcd of strings length and that should be the length of the substring.

```python
import math

def find_gcd_strings(str1, str2):
    if str1 + str2 != str2 + str1:
        return None # lets return None instead if "" for better print

    gcd = math.gcd(len(str1), len(str2))
    return str1[:gcd]

str1 = "ABCABC"
str2 = "ABC"
print(find_gcd_strings(str1, str2))

str1 = "LEET"
str2 = "CODE"
print(find_gcd_strings(str1, str2))
```
