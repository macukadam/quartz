## Description

<p>There are <code>n</code> cities numbered from <code>0</code> to <code>n - 1</code> and <code>n - 1</code> roads such that there is only one way to travel between two different cities (this network form a tree). Last year, The ministry of transport decided to orient the roads in one direction because they are too narrow.</p>
<p>Roads are represented by <code>connections</code> where <code>connections[i] = [a<sub>i</sub>, b<sub>i</sub>]</code> represents a road from city <code>a<sub>i</sub></code> to city <code>b<sub>i</sub></code>.</p>
<p>This year, there will be a big event in the capital (city <code>0</code>), and many people want to travel to this city.</p>
<p>Your task consists of reorienting some roads such that each city can visit the city <code>0</code>. Return the <strong>minimum</strong> number of edges changed.</p>
<p>It&#39;s <strong>guaranteed</strong> that each city can reach city <code>0</code> after reorder.</p>

## Solution

We can think of brute forcing by starting from each node and trying to reach to 0. That way we can see how many edges that we need to reverse. However we might reverse some edges multiple times since one reverse can help multiple node. So we need to keep track of what we reversed to not do double work. This solution feels quite complicated to implement. 

We can also try to reach every node from zero and keep tracking the reversed edges. In this scenario we would construct a graph. But constructing a directed graph would leave us with unreachable nodes. But if we keep the edges separately and construct a undirected graph.
This way we can traverse the nodes starting from 0 and check edges if the 0 <- A exists, if it's not we can reverse that. And next of course we need to check if A <- B exists. Or 0 <- B exists. 

Let's use bfs to implement the above logic.


```python
from typing import List
from collections import defaultdict, deque


def min_reorder_bfs(n: int, connections: List[List[int]]) -> int:
	# consturct edges for fast look up in a set
    edges = set([(a, b) for a, b in connections])
	
	# construct a indirected graph for traversing freely
    graph = defaultdict(list)
    for a, b in connections:
        graph[a].append(b)
        graph[b].append(a)
    
    # start with 0 visited
    visited = set([0])
    queue = deque([0])
    count = 0
    
    while queue:
        city = queue.popleft()
        
        """ 
        get all the neighbours of the current city, 
        if they are not visited and if the path to the 
        city from the neighbor does not exists increase 
        the counter by one (reflecting a reversal at edge)
        """
        for neighbour in graph[city]:
            if neighbour not in visited:
                visited.add(neighbour)
                if (city, neighbour) in edges:
                    count += 1
                queue.append(neighbour)
    
    return count
	

print(min_reorder(n = 6, connections = [[0,1],[1,3],[2,3],[4,0],[4,5]]))
print(min_reorder(n = 5, connections = [[1,0],[1,2],[3,2],[3,4]]))
print(min_reorder(n = 3, connections = [[1,0],[2,0]]))
```
