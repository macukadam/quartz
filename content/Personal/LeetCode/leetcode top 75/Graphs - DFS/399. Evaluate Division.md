## Description

<p>You are given an array of variable pairs <code>equations</code> and an array of real numbers <code>values</code>, where <code>equations[i] = [A<sub>i</sub>, B<sub>i</sub>]</code> and <code>values[i]</code> represent the equation <code>A<sub>i</sub> / B<sub>i</sub> = values[i]</code>. Each <code>A<sub>i</sub></code> or <code>B<sub>i</sub></code> is a string that represents a single variable.</p>
<p>You are also given some <code>queries</code>, where <code>queries[j] = [C<sub>j</sub>, D<sub>j</sub>]</code> represents the <code>j<sup>th</sup></code> query where you must find the answer for <code>C<sub>j</sub> / D<sub>j</sub> = ?</code>.</p>
<p>Return <em>the answers to all queries</em>. If a single answer cannot be determined, return <code>-1.0</code>.</p>
<p><strong>Note:</strong> The input is always valid. You may assume that evaluating the queries will not result in division by zero and that there is no contradiction.</p>
<p><strong>Note:&nbsp;</strong>The variables that do not occur in the list of equations are undefined, so the answer cannot be determined for them.</p>
<p><strong class="example">Example 1:</strong></p>
<pre>
<strong>Input:</strong> equations = [[&quot;a&quot;,&quot;b&quot;],[&quot;b&quot;,&quot;c&quot;]], values = [2.0,3.0], queries = [[&quot;a&quot;,&quot;c&quot;],[&quot;b&quot;,&quot;a&quot;],[&quot;a&quot;,&quot;e&quot;],[&quot;a&quot;,&quot;a&quot;],[&quot;x&quot;,&quot;x&quot;]]
<strong>Output:</strong> [6.00000,0.50000,-1.00000,1.00000,-1.00000]
<strong>Explanation:</strong> 
Given: <em>a / b = 2.0</em>, <em>b / c = 3.0</em>
queries are: <em>a / c = ?</em>, <em>b / a = ?</em>, <em>a / e = ?</em>, <em>a / a = ?</em>, <em>x / x = ? </em>
return: [6.0, 0.5, -1.0, 1.0, -1.0 ]
note: x is undefined =&gt; -1.0</pre>

## Solution

Let's consider first example: \[\["a","b"\],\["b","c"\]\], values = \[2.0,3.0\]

To get $a / c$ we could use following formula.
$$
\frac{a}{b} \cdot \frac{b}{c} = \frac{a}{c}
$$

Then is $a / c = 6$. 

If we say the smallest value is 1. Then $b = 3 and a = 6$. By just looking it's very easy to tell. To reach $c / a$ we would have to calculate the following:

$$
\frac{b}{a} \cdot \frac{c}{b} = \frac{c}{a}
$$
We can tell that $b / a = 1 / 2$ and $c / b = 1 / 3$ and if we multiply them then $c/a=1/6$

So it's just matter of figuring out a path from a to c and then multiplying the inverted division values. So if we create a bidirectional directed graph with values and inverted values for each equation. Let me show it with a drawing:

Once we create this graph, it's quite straightforward to generate calculations in any direction.
Just move from one node to another while multiplying the values in those edges. If we do not have a path then that means return -1. 

To find the node we can use dfs or bfs.

Let's code this logic:

```python
from typing import List
from collections import defaultdict, deque


def calculate_queries(equations: List[List[int]], values: List[int], queries: List[List[str]]) -> List[int]:
	graph = defaultdict(dict)
	
	for i, (dividend, divisor) in enumerate(equations):
		graph[dividend][divisor] = values[i]
		graph[divisor][dividend] = 1 / values[i]
		
	def bfs(query):
		queue = deque()
		a, b = query
		if a == b: return 1
		
		queue.append(graph[a])
		visited = set()
		visited.add(a)
		curr_weight = 1
		
		while queue:
			neighbors = queue.popleft()
			
			for node, weight in neighbors.items():
				if node in visited:
					continue
				
				if node == b:
					return curr_weight * weight
				else: 
					curr_weight *= weight
					
				visited.add(node)
				queue.append(graph[node])
			
		return -1
		
	return [bfs(q) for q in queries]

equations = [["a","b"],["b","c"]]
values = [2.0,3.0]
queries = [["a","c"],["b","a"],["a","e"],["a","a"],["x","x"]]
print(calculate_queries(equations, values, queries))

equations = [["a","b"],["b","c"],["bc","cd"]]
values = [1.5,2.5,5.0]
queries = [["a","c"],["c","b"],["bc","cd"],["cd","bc"]]
print(calculate_queries(equations, values, queries))

values = [2.0,3.0]
```
