## Description

<p>Given the <code>root</code> of a binary tree, return <em>its maximum depth</em>.</p>
<p>A binary tree&#39;s <strong>maximum depth</strong>&nbsp;is the number of nodes along the longest path from the root node down to the farthest leaf node.</p>
<p><strong class="example">Example 1:</strong></p>
![[Personal/LeetCode/Assets/LetCode Assets/maximum-depth-of-binary-tree_0.jpg]]
<pre>
<strong>Input:</strong> root = [3,9,20,null,null,15,7]
<strong>Output:</strong> 3
</pre>
<p><strong class="example">Example 2:</strong></p>
<pre>
<strong>Input:</strong> root = [1,null,2]
<strong>Output:</strong> 2
</pre>
<p><strong>Constraints:</strong></p>
<ul>
	<li>The number of nodes in the tree is in the range <code>[0, 10<sup>4</sup>]</code>.</li>
	<li><code>-100 &lt;= Node.val &lt;= 100</code></li>
</ul>

---
## Solution

Max depth is usually found using DFS. And this question is no exception.

```python
from algos.binarytree import Node

def max_depth_of_binary_tree(root: Node):
    if not root:
        return 0
        
    return 1 + max(max_depth_of_binary_tree(root.left), max_depth_of_binary_tree(root.right))
	
root = Node.create_binarytree([3,9,20,None,None,15,7])
print(max_depth_of_binary_tree(root))

root = Node.create_binarytree([1,None,2])
print(max_depth_of_binary_tree(root))
```
