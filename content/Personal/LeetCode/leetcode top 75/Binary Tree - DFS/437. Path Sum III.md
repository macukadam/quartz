## Description

<p>Given the <code>root</code> of a binary tree and an integer <code>targetSum</code>, return <em>the number of paths where the sum of the values&nbsp;along the path equals</em>&nbsp;<code>targetSum</code>.</p>
<p>The path does not need to start or end at the root or a leaf, but it must go downwards (i.e., traveling only from parent nodes to child nodes).</p>
<p><strong class="example">Example 1:</strong></p>

![[Personal/LeetCode/Assets/LetCode Assets/path-sum-iii_0.jpg]]
<pre>
<strong>Input:</strong> root = [10,5,-3,3,2,null,11,3,-2,null,1], targetSum = 8
<strong>Output:</strong> 3
<strong>Explanation:</strong> The paths that sum to 8 are shown.
</pre>
<p><strong class="example">Example 2:</strong></p>
<pre>
<strong>Input:</strong> root = [5,4,8,11,null,13,4,7,2,null,null,5,1], targetSum = 22
<strong>Output:</strong> 3
</pre>
<p><strong>Constraints:</strong></p>
<ul>
	<li>The number of nodes in the tree is in the range <code>[0, 1000]</code>.</li>
	<li><code>-10<sup>9</sup> &lt;= Node.val &lt;= 10<sup>9</sup></code></li>
	<li><code>-1000 &lt;= targetSum &lt;= 1000</code></li>
</ul>

# Solution

### Brute force

Brute force solution is pretty straightforward. Just traverse list from every node and search targetSum value by reducing node.value at every level. If we hit targetSum = node.val that means we found a target sum. Increase the counter by one.

```python
from algos.binarytree import Node
 
def dfs(node: Node, targetSum: int):
	if not node:
		return 0 
		
	count = test(node, targetSum)
	count += dfs(node.left, targetSum)
	count += dfs(node.right, targetSum)
	
	return count
 
def test(node: Node, targetSum:int):
	if not node:
		return 0 
	
	count = 1 if targetSum == node.val else 0
	
	count += test(node.left, targetSum - node.val)
	count += test(node.right, targetSum - node.val)
	
	return count

root = Node.create_binarytree([10,5,-3,3,2,None,11,3,-2,None,1])
print(dfs(root, 8))

root = Node.create_binarytree([5,4,8,11,None,13,4,7,2,None,None,5,1])
print(dfs(root, 22))
```

In the figure above you can see that we started the hashmap from {0: 1}
that's to cover currentSum - target = 0 case. You can see that that case is covered when we hit 1 + 3 + 1. Then we compare if there is a previous sum value of 0 since currentSum - target = 0. If we did not fill hashmap with the zero seen once frequency we would miss that sweet spot.

Other than that at the last node we hit currentSum - target = 5. 5 appeared earlier twice in the branch as currentSum. That means we can draw two sub paths from currentSum 5 to the last node. One is the third node valued as 1.
So the sums were already equal to 5 when we hit that node. That means from 5 to 10 there is 5 difference. 5 - 4 - 1 + 5 = 5. That's one path. And the other path starts right after -1 seen. From there there is 5 which is the node itself. Since frequency of 5 was 2 in the hashmap we know by fact that we have 2 paths that we can draw from the root. Then we increase count by 2.

Lastly when we propagate up once we complete one path, we need to reduce the frequency of the currentSum at the end of the execution by one. So that that node is not gonna considered as a valid candidate since it's out of the scope .

Let's implement that algorithm now.

```python
from collections import defaultdict
from algos.binarytree import Node

hashmap = defaultdict(int)
hashmap[0] = 1


def dfs(node: Node, target: int, current_sum: int):
    if not node:
        return 0 

    current_sum += node.val
    expected_sum = current_sum - target

    count = hashmap[expected_sum]
    hashmap[current_sum] += 1

    count += dfs(node.left, target, current_sum)
    count += dfs(node.right, target, current_sum)
    hashmap[current_sum] -= 1
    return count


	
root = Node.create_binarytree([10,5,-3,3,2,None,11,3,-2,None,1])
print(dfs(root, 8, 0))

root = Node.create_binarytree([5,4,8,11,None,13,4,7,2,None,None,5,1])
print(dfs(root, 22, 0))

# let's also try the example in the figure
root= Node.create_binarytree([1,3,None,1,None,5,None,-4,None,-1,None,5])
print(dfs(root, 5, 0))
```
