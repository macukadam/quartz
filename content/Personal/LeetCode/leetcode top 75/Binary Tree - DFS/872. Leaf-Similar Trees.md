## Description

<p>Consider all the leaves of a binary tree, from&nbsp;left to right order, the values of those&nbsp;leaves form a <strong>leaf value sequence</strong><em>.</em></p>
<p><img alt="" src="../../../../Assets/LetCode Assets/leaf-similar-trees_0.png" style="width: 400px; height: 336px;" /></p>
<p>For example, in the given tree above, the leaf value sequence is <code>(6, 7, 4, 9, 8)</code>.</p>
<p>Two binary trees are considered <em>leaf-similar</em>&nbsp;if their leaf value sequence is the same.</p>
<p>Return <code>true</code> if and only if the two given trees with head nodes <code>root1</code> and <code>root2</code> are leaf-similar.</p>
<p><strong class="example">Example 1:</strong></p>
<img alt="" src="../../../../Assets/LetCode Assets/leaf-similar-trees_1.jpg" style="width: 600px; height: 237px;" />
<pre>
<strong>Input:</strong> root1 = [3,5,1,6,2,9,8,null,null,7,4], root2 = [3,5,1,6,7,4,2,null,null,null,null,null,null,9,8]
<strong>Output:</strong> true
</pre>
<p><strong class="example">Example 2:</strong></p>
<img alt="" src="../../../../Assets/LetCode Assets/leaf-similar-trees_2.jpg" style="width: 300px; height: 110px;" />
<pre>
<strong>Input:</strong> root1 = [1,2,3], root2 = [1,3,2]
<strong>Output:</strong> false
</pre>
<p><strong>Constraints:</strong></p>
<ul>
	<li>The number of nodes in each tree will be in the range <code>[1, 200]</code>.</li>
	<li>Both of the given trees will have values in the range <code>[0, 200]</code>.</li>
</ul>

```python
from algos.binarytree import Node
from typing import List


def is_leaf_similar_trees(root1: Node, root2: Node):
    list1, list2 = [], []
    
    def _inorder_traversal(node: Node, lst: List[int]):
        if not node:
            return
            
        _inorder_traversal(node.left, lst)
        if not node.left and not node.right:
            lst.append(node.val)
        _inorder_traversal(node.right, lst)
        
        
    _inorder_traversal(root1, list1)
    _inorder_traversal(root2, list2)
    return list1 == list2
```




```python
root1 = [3,5,1,6,2,9,8,None,None,7,4]
root2 = [3,5,1,6,7,4,2,None,None,None,None,None,None,9,8]

root1 = Node.create_binarytree(root1)
root2 = Node.create_binarytree(root2)
res = is_leaf_similar_trees(root1, root2)
print(res)
```
