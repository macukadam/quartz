## Description

<p>Consider all the leaves of a binary tree, from&nbsp;left to right order, the values of those&nbsp;leaves form a <strong>leaf value sequence</strong><em>.</em></p>

![[Personal/LeetCode/Assets/LetCode Assets/leaf-similar-trees_0.png]]
<p>For example, in the given tree above, the leaf value sequence is <code>(6, 7, 4, 9, 8)</code>.</p>
<p>Two binary trees are considered <em>leaf-similar</em>&nbsp;if their leaf value sequence is the same.</p>
<p>Return <code>true</code> if and only if the two given trees with head nodes <code>root1</code> and <code>root2</code> are leaf-similar.</p>
<p><strong class="example">Example 1:</strong></p>

</pre>

## Solution

A node without children is called a leaf node. We are tasked with finding all the leaf nodes in a binary tree and comparing them with another tree in left-to-right order.

This problem can be solved using either BFS or DFS; the approach does not affect the time complexity since we need to traverse both trees once.

The time complexity is O(N + M), where N and M are the number of nodes in each tree. The space complexity is O(N) in the worst case, which happens when the tree is completely skewed and all nodes are leaves, so we end up storing all leaf values (plus recursion stack).

We will use DFS to collect the leaf nodes of both trees and then compare the resulting sequences.

```python
from typing import List
from algos.binarytree import Node


def compare(bt1: Node, bt2: Node) -> bool:
	def dfs(root: Node, leaf_nodes: List[int]):
		if not root: return 
		
		if not root.left and not root.right:
			leaf_nodes.append(root.val)
			
		dfs(root.left, leaf_nodes)
		dfs(root.right, leaf_nodes)
		return leaf_nodes

	return dfs(bt1, []) == dfs(bt2, [])
	

root1 = Node.create_binarytree([3,5,1,6,2,9,8,None,None,7,4])
root2 = Node.create_binarytree([3,5,1,6,7,4,2,None,None,None,None,None,None,9,8])
print(compare(root1, root2))

root1 = Node.create_binarytree([1, 2, 3])
root2 = Node.create_binarytree([1, 3, 2])
print(compare(root1, root2))
```
